# SkVoid UI Kit

Componentes principais utilizados no frontend:

- **NeonCard** – Cartões com borda neon azul para destacar métricas da carteira, antifraude e chat.
- **PlansSection** – Grid responsivo com cartões dos quatro planos de assinatura.
- **SecurityHighlights** – Destaques com foco em segurança, antifraude e auditoria.
- **Tema** – Tailwind com base em preto + azul neon, tipografia Rajdhani e sombras `shadow-neon`.

Utilize as classes utilitárias de Tailwind para manter o tema consistente. Todos os textos padrão são PT-BR e devem seguir o tom gamer-profissional.
